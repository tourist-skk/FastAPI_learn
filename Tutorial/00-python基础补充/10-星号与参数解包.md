# 10-星号与参数解包

本篇讲解 Python 中单星号 `*`、双星号 `**` 的常见作用，重点理解新增书籍时的：

```python
new_book = Book(**book.model_dump())
```

这里的 `**` 表示**把字典展开为关键字参数**。它是 Python 的通用语法，普通函数和类的构造调用都可以使用，不是 FastAPI 或 SQLAlchemy 独有的功能。

**判断星号的含义，要同时看“几个星号”和“出现在哪里”。** 在参数列表中、在赋值左边、在两个数之间，含义可能完全不同。

## 一、先理解位置参数与关键字参数

```python
def show_book(bookname, author):
    print(bookname, author)


show_book("Python入门", "张三")                # 按位置传参
show_book(bookname="Python入门", author="张三")  # 按参数名传参
```

两次都输出 `Python入门 张三`。

- **位置参数**：按顺序对应，第一项交给 `bookname`，第二项交给 `author`。
- **关键字参数**：写成 `参数名=值`，按名字对应。

后面会用到两个术语：

- **解包**：把一个容器里的内容展开。例如把列表的两项变成两个位置参数。
- **收集参数**：把传入的多个参数放进一个容器。例如把三个位置参数收集成元组。

## 二、单星号 * 的作用

### 1. 调用函数时：把可迭代对象展开为位置参数

```python
def show_book(bookname, author):
    print(bookname, author)


values = ["Python入门", "张三"]
show_book(*values)

# 等价于：
show_book("Python入门", "张三")
```

`*values` 会依次取出列表中的元素，作为两个位置参数传入。

如果写 `show_book(values)`，就是把整个列表作为**一个参数**交给 `bookname`，还缺少 `author`，因此报 `TypeError`。

**适用场景：**已经有列表、元组等数据，而目标函数需要接收多个位置参数。这里要求的是“可迭代对象”，不只限于列表；元组、字符串、生成器等也可以展开。

### 2. 定义函数时：*args 收集多余的位置参数

```python
def show_prices(title, *prices):
    print(title)
    print(prices)
    print(type(prices))


show_prices("书籍价格", 30, 40, 50)
# 书籍价格
# (30, 40, 50)
# <class 'tuple'>

show_prices("书籍价格")
# 书籍价格
# ()
# <class 'tuple'>
```

第一个位置参数交给 `title`，剩下的位置参数收集进 `prices`，它是一个**元组**。没有剩余参数时，得到空元组 `()`。

常见写法是 `def func(*args):`，但 `args` 只是习惯名称，换成 `prices`、`items` 等也可以；发挥语法作用的是前面的 `*`。

注意定义和调用的方向：

```python
def collect(*args):  # 定义：把多个位置参数收集成元组
    print(args)


values = [10, 20, 30]
collect(*values)     # 调用：先把列表展开为多个位置参数
# (10, 20, 30)
```

### 3. 定义函数时：单独的 * 限制后面的参数必须按名字传入

```python
def set_price(book_id, *, price):
    print(book_id, price)


set_price(1, price=39.0)  # 正确：1 39.0
# set_price(1, 39.0)     # TypeError：price 必须使用关键字传入
```

这个 `*` 后面没有变量名，**不负责收集数据**，只用于分隔参数。它后面的 `price` 是“仅限关键字参数”。

`*args` 后面继续定义的普通参数，也只能按名字传入，例如 `def func(*args, enabled=True):` 中的 `enabled`。[Python 特殊参数](https://docs.python.org/zh-cn/3.11/tutorial/controlflow.html#special-parameters)

### 4. 解包赋值时：接收剩余元素

```python
first, *middle, last = [10, 20, 30, 40]
print(first)   # 10
print(middle)  # [20, 30]
print(last)    # 40

first, *rest = (10, 20, 30)
print(rest)    # [20, 30]，即使右边是元组，rest 仍然是列表

first, *rest = [10]
print(rest)    # []
```

这里的星号出现在**赋值语句左边**，表示把其他变量没有接收的元素收集进列表。

与函数定义中的 `*args` 区分：**赋值左边的星号目标得到列表；函数中的 `*args` 得到元组。**

同一层解包赋值最多只能有一个星号目标。`a, *b, *c = [1, 2, 3]` 会报语法错误，因为不能同时规定两个目标接收剩余元素。[解包赋值规则](https://docs.python.org/zh-cn/3.11/reference/simple_stmts.html#assignment-statements)

### 5. 创建容器时：展开其他可迭代对象

```python
left = [1, 2]
right = [3, 4]

print([*left, *right, 5])  # [1, 2, 3, 4, 5]
print((*left, 3))         # (1, 2, 3)
print(sorted({*left, 2, 3}))  # [1, 2, 3]：集合会去重
```

这里分别把元素展开到新列表、新元组和新集合中，常用于合并数据。它不会把 `left` 或 `right` 本身清空，也不是递归展开：

```python
nested = [[1, 2], [3, 4]]
print([*nested])  # [[1, 2], [3, 4]]，内部列表仍然保留
```

### 6. 两个值之间：乘法或序列重复

```python
print(3 * 4)       # 12：乘法
print("学习" * 2)  # 学习学习：字符串重复
print([1, 2] * 2)  # [1, 2, 1, 2]：列表重复
```

此时的 `*` 是运算符，含义与参数解包不同。

列表重复不会深拷贝内部对象。例如 `[[]] * 3` 中的三个元素指向同一个内部列表；需要三个独立列表时，应使用 `[[] for _ in range(3)]`。

### 7. 导入语句中：导入模块公开的名称

```python
from math import *

print(sqrt(9))  # 3.0
```

这里的 `*` 表示导入模块公开的名称，不是参数解包。模块定义了 `__all__` 时按它导入，否则通常导入不以下划线开头的名称。

日常代码中写 `from math import sqrt` 更方便判断 `sqrt` 来自哪里。

## 三、双星号 ** 的作用

### 1. 调用函数时：把字典展开为关键字参数

```python
def show_book(bookname, author):
    print(bookname, author)


data = {
    "bookname": "Python入门",
    "author": "张三",
}

show_book(**data)

# 等价于：
show_book(bookname="Python入门", author="张三")
```

展开时，**字典的键成为参数名，字典的值成为参数值**。数据按名字对应参数，不靠字典中的先后顺序。

这里要求 `data` 是映射对象，最常用的就是字典；**调用时展开的键必须是字符串**。参数名还必须能被目标函数接收。

目标函数不必定义 `**kwargs` 才能这样调用。上面的 `show_book` 只有两个普通参数，也能通过 `show_book(**data)` 接收数据。[函数调用与参数展开](https://docs.python.org/zh-cn/3.11/reference/expressions.html#calls)

### 2. 定义函数时：**kwargs 收集多余的关键字参数

```python
def show_details(bookname, **details):
    print(bookname)
    print(details)
    print(type(details))


show_details("Python入门", author="张三", price=39.0)
# Python入门
# {'author': '张三', 'price': 39.0}
# <class 'dict'>
```

`bookname` 接收书名；其他没有对应普通参数的关键字参数，被收集到 `details` 字典中。

常见名称是 `kwargs`，表示 keyword arguments（关键字参数）。名字可以更换，起作用的是 `**`；没有多余关键字参数时得到 `{}`。

可以同时使用 `*args` 和 `**kwargs`：

```python
def inspect_arguments(*args, **kwargs):
    print(args)
    print(kwargs)


inspect_arguments(1, 2, bookname="Python入门", price=39.0)
# (1, 2)
# {'bookname': 'Python入门', 'price': 39.0}
```

`*args` 收集位置参数，`**kwargs` 收集关键字参数。这里两个容器内容不同，不会把所有参数重复收集两遍。

### 3. 创建字典时：展开并合并映射内容

```python
base = {"bookname": "Python入门", "price": 30.0}
changes = {"price": 39.0, "author": "张三"}

data = {**base, **changes}
print(data)
# {'bookname': 'Python入门', 'price': 39.0, 'author': '张三'}
```

两份映射的键值对被放入一个新字典。**重复键采用后面的值**，所以上例价格是 `39.0`；原来的 `base` 不会因此被修改。

与函数调用不同，字典中的键不一定是字符串，例如 `{**{1: "甲"}, **{2: "乙"}}` 合法。但把含整数键的字典用于 `func(**data)` 就会报错。

### 4. 两个数之间：幂运算

```python
print(2 ** 3)  # 8，即 2 的 3 次方
print(5 ** 2)  # 25，即 5 的平方
```

`a ** b` 是幂运算；`func(**data)` 是关键字参数解包。两者只是使用了同样的符号。

## 四、回到新增书籍：Book(**book.model_dump()) 到底做了什么

### 1. 请求体先变成 Pydantic 模型实例

假设客户端发送：

```json
{
  "bookname": "FastAPI数据库实践",
  "author": "张三",
  "price": 59.0,
  "publisher": "学习出版社"
}
```

路由参数声明为 `book: BookBase` 后，FastAPI 将请求体解析、校验为 `BookBase` 实例。这里的 `book` 是请求模型对象，还不是 ORM 对象，也不是 JSON 字符串。

### 2. model_dump() 得到字段字典

在路由中：

```python
data = book.model_dump()

print(type(data))  # <class 'dict'>
print(data)
# {
#     'bookname': 'FastAPI数据库实践',
#     'author': '张三',
#     'price': 59.0,
#     'publisher': '学习出版社'
# }
```

`model_dump()` 负责从 Pydantic 模型导出字段数据；这一步与星号无关。[Pydantic 序列化](https://docs.pydantic.dev/latest/concepts/serialization/#python-mode)

### 3. **data 把字典展开，交给 Book 的构造方法

```python
new_book = Book(**data)
```

对于上面的字典，这次调用等价于：

```python
new_book = Book(
    bookname="FastAPI数据库实践",
    author="张三",
    price=59.0,
    publisher="学习出版社",
)
```

当前 `Book` 模型没有自己编写 `__init__`，SQLAlchemy 的声明式映射会提供默认构造方法，允许用这些模型属性名作为关键字参数初始化对象。[SQLAlchemy 默认构造方法](https://docs.sqlalchemy.org/en/20/orm/mapping_styles.html#default-constructor)

因此三部分的职责是：

1. `book.model_dump()`：得到字典。
2. `**`：把字典转换为这次调用的关键字参数。
3. `Book(...)`：根据这些参数创建 ORM 对象，赋给 `new_book`。

`**` 本身不会创建对象、校验字段类型或写入数据库，也不会修改输入字典。**展开只处理这一层，不会把嵌套字典自动变成关联 ORM 对象。**

### 4. 创建对象后，再执行 ORM 新增流程

下面几行放在现有的异步新增路由内部：

```python
data = book.model_dump()
new_book = Book(**data)
db.add(new_book)
await db.commit()
```

它们对应：

```text
JSON 请求体
    ↓ FastAPI 解析、Pydantic 校验
BookBase 实例 book
    ↓ book.model_dump()
dict 字典 data
    ↓ Book(**data)：按名字传参并创建对象
Book 实例 new_book
    ↓ add() + commit()
数据库记录
```

原脚本中的 `Book(**book.__dict__)` 也使用同一种双星号解包语法，只是取得字典的方式不同。对当前请求模型，使用 `model_dump()` 更明确；不要把任意对象的 `__dict__` 都当作可直接插入数据库的字段集合。

具体事务流程见 [第 25 节：新增数据](../25-FastAPI进阶-ORM操作数据-新增数据/25-FastAPI进阶-ORM操作数据-新增数据.md)。

## 五、常见混淆与错误

### 1. *data 和 **data 不是一回事

```python
def show_book(bookname, author):
    print(bookname, author)


data = {"bookname": "Python入门", "author": "张三"}

show_book(*data)   # bookname author：展开的是字典的键
show_book(**data)  # Python入门 张三：按键名传入对应的值
```

字典被普通迭代时取出的是键，因此 `*data` 不会自动展开字典的值。

在当前 ORM 模型中：

- `Book(data)`：把整个字典作为一个位置参数传入，不符合当前默认构造方法的要求。
- `Book(*data)`：把字典的键作为多个位置参数传入，也不符合要求。
- `Book(**data)`：把键值对作为关键字参数传入，才是本节需要的写法。

### 2. 函数调用中，重复参数会报错

```python
def set_price(price):
    print(price)


data = {"price": 39.0}
# set_price(price=30.0, **data)  # TypeError：price 被传了两次
# set_price(**data, **data)     # TypeError：重复的关键字参数
# set_price(30.0, **data)       # TypeError：位置和关键字都给了 price
```

不要把 `{**a, **b}` 的覆盖规则套到 `func(**a, **b)`：

- 字典合并：重复键由后面的值覆盖。
- 函数调用：同一个参数重复传入会报错，即使函数定义了 `**kwargs` 也一样。

### 3. 星号不会忽略错误的字段

```python
def show_book(bookname, author):
    print(bookname, author)


# show_book(**{"bookname": "Python入门"})
# TypeError：缺少必需的 author 参数

# show_book(**{"bookname": "Python入门", "author": "张三", "price": 39})
# TypeError：函数不接收 price，也没有 **kwargs 来收集它

# show_book(**{1: "Python入门"})
# TypeError：用于关键字参数展开的键必须是字符串
```

对于当前 `Book`，传入模型不接受的属性名通常会在构造时报错；但漏掉必填数据库列，可能直到 `flush()` 或 `commit()` 才触发数据库约束异常。**Python 参数匹配、模型构造和数据库校验是不同步骤。**

### 4. 多个展开表达式可以并用，但没有 *** 参数语法

```python
def inspect_arguments(*args, **kwargs):
    print(args)
    print(kwargs)


inspect_arguments(*[1, 2], *[3], **{"author": "张三"}, **{"price": 39})
# (1, 2, 3)
# {'author': '张三', 'price': 39}
```

这是分别使用了多个 `*表达式`、`**表达式`，不是把星号数量不断增加。`Book(***data)` 不是合法的 Python 参数语法，双星号也不是“把单星号解包连续做两次”。
